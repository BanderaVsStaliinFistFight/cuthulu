#####################################################################
# Eldritch Pacts - events
#
#   eldritch.1        the forbidden lore is found
#   eldritch.2        welcome message for human players at game start
#   eldritch.11/13/16 a summoning succeeds (Cthulhu, Hastur, Azathoth)
#   eldritch.20/30    the pact deepens (tier II / tier III)
#   eldritch.31/33/36 the god is incarnated as a division (Cthulhu, Hastur, Azathoth)
#   eldritch.40-43    the patron's whims (random, monthly)
#   eldritch.60/61    received by the target of a curse
#   eldritch.63       received by a cursed enemy whose name the Prophet speaks
#   eldritch.70/71    the Prophet communes with the god (asks / returns changed)
#   eldritch.72       the Prophet becomes the god's Vessel
#   eldritch.80       the Prophet's record: the character sheet
#   eldritch.81       the Prophet reaches a new level
#   eldritch.82       the result of a skill check (roll, odds, outcome)
#   eldritch.201-273  the Prophet's quests: approach, success, failure
#                     (201 Necronomicon, 211 Cthulhu, 231 Hastur,
#                     261 Azathoth, 271 At the Mountains of Madness)
#   eldritch.290      a quest's task ran out of time
#   eldritch.311-363  The Road to Carcosa, Hastur's questline: chapter n is
#                     3n1 (approach), 3n2 (success), 3n3 (failure)
#   eldritch.370      Carcosa is proclaimed
#   eldritch.100      hidden monthly pulse (Favor income, random whims)
#   eldritch_news.1-3 world news: a god is summoned / ascends / incarnates
#   eldritch_news.4   world news: a leader becomes a god's Vessel
#   eldritch_news.5   world news: a nation proclaims itself Carcosa
#####################################################################
